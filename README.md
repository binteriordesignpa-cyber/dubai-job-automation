# Dubai Job Automation 🤖🇦🇪

AI-assisted workflow for finding, matching, preparing, tracking, and following up on Dubai interior-design job opportunities.

## Workflow
**Master Agent → Job Search → Job Match → CV → Application → Tracking → Follow-up → Interview**

## Candidate Profile
- Experience: 13 years
- Interior Design
- AutoCAD
- SketchUp
- V-Ray
- Photoshop
- Project Management
- Shop Drawings
- Procurement

## Database
Planned Supabase tables: `candidate`, `skills`, `jobs`, `job_matches`, `documents`, `applications`, `follow_ups`, `interviews`, `agent_tasks`, `activity_log`.

## Security
Never commit API keys, passwords, tokens, or private credentials. Use environment variables for secrets.

## Application Control
If a platform requires CAPTCHA, legal attestation, identity verification, or another user-only action, the workflow must pause for the user.
